## 六、不建议做的事

| 不要做 | 原因 |
|---|---|
| 加"整房超时自动清场" | 会摧毁慢节奏战斗，历史 Bug 复发（步骤 25 会失败） |
| 给 `pgeo()` 缓存几何加 `disposable` 标记 | 第二层所有道具集体消失 |
| 改 `G.hurtEnemy` 的参数个数/顺序 | 盾卫格挡行为静默反转，无报错 |
| 调 `update()` 的更新顺序 | 命中错位、清剿延迟、增援波错乱 |
| 改门的 4-tile 结构 | 门位置/闸门朝向/隐藏墙朝向同时错乱 |
| "修复"文字精灵的 `depthTest:false` | 商店价格牌被遮挡 |
| 把翻桌的 `blocksBullets` 统一化 | 玩家会被自己的掩体卡住输出 |
| 把对象池满时的"静默丢弃"改成抢占 | 会打断正在播放的关键特效 |
| 引入任何 npm 包 / CDN / 构建工具 | 违反项目根本约束，破坏 `file://` 直开 |
