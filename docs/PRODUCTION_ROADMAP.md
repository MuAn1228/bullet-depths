## 0. 一句话愿景

> 从「功能完整的肉鸽射击小游戏」升级为**玩家愿意反复玩几十小时、愿意推荐给别人、
> 看起来像商业独立游戏**的作品——核心抓手不是内容数量，而是四个体验层。

## 1. 核心框架：四个体验层（现状自评）

外部评审提出的四层框架被采纳为本项目的验收坐标系。**关键校正是：
本项目并非从零起步**——下表「现状」列是 2026-09-03 对代码实况的核对结论。

| 体验层 | 回答的问题 | 现状（已有 ✓ / 缺失 ✗） | 缺口判断 |
|---|---|---|---|
| **Combat Feel** 打起来爽不爽 | 命中的每一秒有没有物理感 | ✓ hitstop（击杀/拍立得/JACKPOT）、trauma² 震屏（且已按武器分档）、慢动作、受击闪白、伤害数字、枪口闪光、弹壳 | ✓ 存在但**覆盖不全、强度未系统分级**：普通命中无 hitstop、无曝光脉冲、无 chromatic aberration、音效无音高抖动、两 Boss 无专属演出差异 |
| **Build Identity** 这局有没有个性 | 我的 build 和别人/上局一样吗 | ✓ 15 武器（3 把规则改写型：拍立得/赌徒/电弧链）、18 被动、构筑 HUD、精英词缀 | ✗ **状态效果只有冰霜减速一种**；被动之间几乎全是「加法叠加」，无跨系统联动；无「构筑成型」的高光时刻 |
| **Decision Density** 每次选择有没有代价 | 我该去哪、该买什么 | ✓ 房间类型 10 种（含赌桌/祭坛/隐藏房）、商店定价生态、局外解锁 | ✗ 路线是「走到哪算哪」：无风险标注、无精英房/挑战房、无风险-收益契约；商店购买基本是"数值上就买" |
| **Replayability** 为什么再开一局 | 死了之后想不想立刻重开 | ✓ 局外里程碑解锁 10 武器、种子化生成、三层差异化（敌人池/陷阱/主题/BGM） | ✗ 种子未暴露给玩家；无每日挑战；无图鉴/收藏；死亡结算信息薄；通关即毕业（无 Loop 难度） |

**结论**：四个层全部「有地基、没封顶」。接下来的批次按 L1→L4 补齐，
内容量产（L6）刻意放在最后。

## 2. 阶段模型

```
[已达成] 垂直切片 1.0：玩法闭环成立（移动→射击→清房→掉落→构筑→商店→三层→Boss→胜利）
   ↓
M0  质量地基：已知缺陷清零 + 战斗反馈补差          ← 下一批就做这个
   ↓
M1  Vertical Slice 2.0：Build Engine + 死亡结算     ← 「玩家为什么再开一局」的答案开始成立
   ↓
M2  Production Quality：决策系统 + Boss 演出 + 动态音乐
   ↓
M3  Replayability：每日/图鉴/角色 + 打包可行性验证
   ↓
M4  Steam-ready：发行工程（成就/云存档/本地化/无障碍）
```

## 3. 任务清单

> 优先级：**S**（决定游戏成败）· **A**（决定商业完成度）· **B**（锦上添花）· **C**（暂不做）。
> 规模：**S**=单批次 · **M**=1~2 批次 · **L**=3+ 批次 · **XL**=需要架构决策。

### L1 · Combat Polish（S · 绝对第一优先级）

> 原则：**同样的 DPS，体感完全不同**。命中链路的每一环都要有反馈。
> 目标链路：点击 → 枪口闪光 → 后坐力 → 枪身动画 → 弹壳 → 枪声 → 拖尾 → 命中 →
> 受击动画 → Hit Stop → 屏幕微震 → 粒子 → 数字。

| 编号 | 任务 | 现状 → 要做 | 验收 | 规模 |
|---|---|---|---|---|
| R1.1 | 命中反馈分级 | 击杀有 hitstop(.03)，普通命中无 → 命中即 0.02~0.03s hitstop（Boss/大体型延长至 0.06） | 15 把武器逐一过「手感审计表」（见 R1.5），普通命中可感知"打到它了" | M |
| R1.2 | 震屏强度统一分档 | 已按武器类型分档但数值离散 → 五档制：普弹 .5 / 霰弹 1 / 火箭 2 / 爆炸 3 / Boss 重击 4（映射到 trauma 值），并给敌人攻击也分档 | 表驱动一处可查全部档位；Boss 重击与普弹体感差异明显 | S |
| R1.3 | 命中曝光脉冲 | 无 → 命中/Boss 阶段切换时 `screenFlash` 极短低强度白脉冲（复用拍立得已有的机制，抽成通用 API） | 需在 fx.js 加通用入口；屏闪开关（R7.2）关闭时不触发 | S |
| R1.4 | 音效音高抖动 | 所有 sfx 每次完全同音 → `_osc/_noise` 统一加 ±3~5% 随机 pitch（音乐除外） | 连续射击 30 发无"机关枪磁带感"；自测不因音频变化而挂 | S |
| R1.5 | 手感审计表 | 无 → 新建 `docs/COMBAT_FEEL_AUDIT.md`：15 武器 × 13 环节逐格打勾，缺口即 L1 待办 | 表格全绿；挂进 PROCEDURES 作为武器改动后的检查单 | S |
| R1.6 | 击杀演出升级 | 击杀=poof+血雾+hitstop → 按敌人体型分 2~3 档：小怪现状；精英/Boss 出血量+击退+短暂 hitstop 延长 | Boss 击杀应有"这是这个游戏最爽的 3 秒"（配合 R4.4） | M |

### L2 · Build Engine（S · 从小游戏到肉鸽的分水岭）

> 原则：**Build 必须改变行为，而不是加数值**。武器+被动+状态+环境之间产生联动，
> 玩家在某一局突然意识到"我的构筑成型了"——这是肉鸽最爽的瞬间。

| 编号 | 任务 | 现状 → 要做 | 验收 | 规模 |
|---|---|---|---|---|
| R2.1 | 状态效果框架 | 只有冰霜减速（`e.slowT`）→ 通用 DoT/状态系统：燃烧（周期伤害）/ 感电（受击增幅/小段连锁）/ 流血（移动加剧），挂 `E.update` 既有状态段，配视觉与音效标识 | 三种状态各自可施加/可叠加/可致死/可被照片态冻结；互不破坏现有 slowT | L |
| R2.2 | 关键词 Tag 系统 | 无 → 武器/被动/敌人/道具打标签（FIRE/ELECTRIC/EXPLOSIVE/BLEED/CRIT/PROJECTILE/RELOAD/DASH/POISON…），联动效果按 Tag 对查询 | Tag 表单一来源；至少 6 组联动由 Tag 驱动而非硬编码 | L |
| R2.3 | 三个构筑原型 | 无 → 火焰（点燃→死亡传播）、电击（链式+金属增伤）、低血量（<30% 全增益+吸血/护盾支撑）各成完整闭环 | 每个原型能在一局内成型并被构筑 HUD 命名（R2.5）；三者玩法体感明显不同 | L |
| R2.4 | 环境联动 | 掩体/桶/罐已存在但仅是物理物 → 环境作为 Build 组件：油桶（点燃→燃烧扩散）、金属掩体（感电传导）、可爆炸物与火焰系联动 | 油桶等新 prop 不破坏既有翻桌/掩体规则（红线：翻桌 blocksBullets 语义不动） | M |
| R2.5 | 构筑命名 | 构筑 HUD 已显示被动标签 → 按 Tag 组合自动生成 Build 名（"火焰炼狱"），死亡结算复用 | 同一 build 稳定产出同一命名；无组合时显示"散兵游勇"之类兜底 | S |
| R2.6 | 稀有度=机制复杂度 | 品阶=数值 → 重定义：普通=数值、稀有=改变子弹行为、史诗=行为+联动、传奇=行为+联动+视觉强化 | 新规则写入武器/道具设计规范，存量武器逐步归类 | M |

### L3 · Decision System（S · 让玩家做选择）

| 编号 | 任务 | 现状 → 要做 | 验收 | 规模 |
|---|---|---|---|---|
| R3.1 | 风险-收益路线 | 地图图已存在但路线无信息量 → 门/路线标注风险等级（精英房/诅咒房/普通），高风险=更高掉落 | 一层内至少 2 次"去哪"的真实权衡；小地图可见标注 | L |
| R3.2 | 精英房 | 精英只随机出现 → 专属精英房：词缀强化版组合 + 固定高价值奖励；外部建议的"时间操纵者/复活者/镜像怪"进词缀池（见 §5 创意池） | 精英房奖励显著高于普通清剿；复用精英词缀系统不另起炉灶 | M |
| R3.3 | 挑战房 | 无 → 房型 `challenge`：限时歼灭 / 无伤 / 弹药限制三类，成功给稀有奖励，失败零惩罚可离开 | 三类各可触发且自测覆盖；失败不软锁（红线：禁止任何超时清场） | M |
| R3.4 | 深渊契约（诅咒系统） | 祭坛/赌桌已存在 → 契约交互：如最大生命 -30% 换全局伤害 +60%，可跨层叠加 | 契约效果可叠加、可在构筑 HUD 查看；与赌桌/祭坛形成风险三件套 | M |
| R3.5 | 层主题=策略变化 | 三层已有差异化（敌人池/陷阱/主题/BGM）→ 每层加一条**改变战斗策略**的层规则（如第 3 层虚空裂隙已有——总结成显式规则并在进入时提示） | 换层后玩家能说出"打法要变"的具体原因 | M |

## 4. 明确不做 / 暂不做（负空间）

| 不做 | 原因 |
|---|---|
| 第 5 层及以上地图 | ~~第 4/5 层不做~~ → 2026-09-05 第四层「失序维度」已完成（独立生成器+主题+流转+4种机制+8种shape+空间裂解者 Boss）。**第 5 层暂不规划**，原则是把深度灌进现有四层 |
